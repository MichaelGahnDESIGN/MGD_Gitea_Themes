# MGD Gitea Themes Wiki

Welcome to the documentation for **MGD Gitea Themes**, a growing collection of custom themes for self-hosted Gitea installations by Michael Gahn DESIGN.

## Start here

If you only want to install a theme, continue with **[Installation](Installation.md)**.

If you want to create or modify a theme, read **[Theme Development](Theme-Development.md)**.

If something looks wrong after an update, use **[Troubleshooting](Troubleshooting.md)** and check **[Compatibility](Compatibility.md)**.

## Current themes

### MGD Black Red

Theme ID: `mgd-black-red`

A deep-black developer theme with anthracite surfaces and precise red accents. It is the first reference theme in the collection and initially targets Gitea 1.27.x.

Source: [`themes/mgd-black-red/theme-mgd-black-red.css`](../../themes/mgd-black-red/theme-mgd-black-red.css)

## Project philosophy

MGD themes should enhance Gitea rather than fight it. Themes remain CSS-based, avoid modifications to Gitea core files and prioritize readability of repositories, code, diffs, issues and pull requests over decoration.
